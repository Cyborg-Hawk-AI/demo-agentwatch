# AgentWatch

> Lightweight dashboard that monitors long-running AI agent jobs and sends smart progress digests.

## What is AgentWatch?

AgentWatch is built for **AI workflow developers and automation engineers running multi-step or long-running AI agent pipelines who need visibility without babysitting**. Zero-dependency REST ping API means any agent framework (LangChain, CrewAI, custom Python) can integrate in 2 lines of code; no SDK lock-in

### Core MVP features
- SDK-less integration: agents ping a simple REST endpoint with status updates
- Real-time job timeline view showing each agent step, duration, and output summary
- Smart digest emails/Slack messages: 'Your agent completed 4/6 steps; step 3 took 12 min (2x normal)'
- Anomaly detection: flags jobs that stall, loop, or exceed expected duration
- Dead-man's switch: if an agent stops reporting for N minutes, trigger an alert or fallback webhook

**Pricing:** Usage-based SaaS: free tier (3 agents, 500 pings/month), paid tiers by ping volume at $19/month for 10k pings; $49/month for 100k pings; $149/month for unlimited

## How this business runs itself (mailbox money)

The goal is passive, low-maintenance recurring revenue: AI is how we build and operate the business, not necessarily what it sells.

Agent pings arrive at the REST endpoint and are written to Supabase in real time. A cron Edge Function checks for stalled jobs every minute and fires webhooks/alerts automatically. Weekly digest emails are LLM-generated from job history and sent via Resend. Stripe manages all subscription events. Support is handled by an AI chat widget. Owner time: under 1 hour/week.

**Estimated owner time:** ~1 hour(s)/week

**MVP estimate:** FastAPI + Supabase + Resend + Slack API; simple React dashboard; 2.5 weeks to launch
